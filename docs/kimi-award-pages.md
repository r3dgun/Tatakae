# Kimi Award Ecommerce Pages

The uploaded Kimi-style ecommerce HTML has been added without design conversion or CSS/JS rewriting.

## Routes

- Blazor wrapper route: `/kimi-award`
- Direct static page: `/kimi-award/index.html`

## Why it is embedded as a static page

The user requested no design changes. The safest approach is to keep the original HTML, CSS, inline assets, and JavaScript untouched and expose it inside the Blazor WebAssembly project through a clean route.
