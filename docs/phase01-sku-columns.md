# SKU editor columns

The admin product SKU editor now shows explicit labels for every field and no longer uses the generic `.wide` class that conflicted with storefront/mobile styles.

Right-to-left column meaning in each SKU row:

1. کد SKU
2. سایز
3. نام رنگ
4. کد رنگ HEX
5. قیمت اصلی
6. قیمت تخفیف
7. موجودی کل
8. رزرو شده
9. هشدار کم‌موجودی
10. بارکد
11. تصویر همین SKU
12. فعال/غیرفعال
13. حذف SKU

Ready-made products use the selected SKU directly and do not enter the studio. Studio products use the SKU as the garment/size/color base before customization.
