# Phase 09 - Admin Dashboard & Reports

این مرحله داشبورد مدیریت را از حالت خلاصه ساده به مرکز کنترل فروشگاه تبدیل می‌کند.

## قابلیت‌های اضافه‌شده

- فروش کل، فروش امروز و فروش ماه جاری
- میانگین ارزش سفارش
- تعداد پرداخت‌های معلق و مبلغ آن‌ها
- شمارش سفارش‌ها در خط تولید: پرداخت، بررسی طرح، گلدوزی، کنترل کیفیت، بسته‌بندی، ارسال و تحویل
- هشدار SKU کم‌موجودی و ناموجود
- شمارش نظرهای در انتظار تأیید
- شمارش پرسش‌های بی‌پاسخ
- شمارش طرح‌های گلدوزی در انتظار بررسی و نیازمند اصلاح
- لیست کارهای فوری ادمین با لینک مستقیم به صفحه مربوطه
- پرفروش‌ترین محصولات بر اساس سفارش‌های پرداخت‌شده
- کارت سلامت فروشگاه برای محصول آماده، محصول استودیویی و موجودی قابل فروش

داشبورد فقط داده‌های عملیاتی را نمایش می‌دهد و برای تغییر وضعیت سفارش، پرداخت، طرح، سؤال، نظر یا موجودی کاربر را به صفحه تخصصی همان بخش هدایت می‌کند.
