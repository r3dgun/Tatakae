# Phase 01 - Catalog, SKU and Inventory foundation

این مرحله پایه فروشگاه را کامل‌تر می‌کند تا مراحل بعدی مثل سفارش، ارسال، پرداخت و تخفیف روی مدل درست ساخته شوند.

## انجام‌شده

- هر واریانت محصول به‌عنوان SKU واقعی مدیریت می‌شود.
- برای SKU فیلدهای زیر اضافه شد:
  - `ReservedQuantity`
  - `AvailableQuantity`
  - `LowStockThreshold`
  - `ImageUrl`
  - `Barcode`
- اعتبارسنجی ادمین اضافه شد:
  - SKU تکراری داخل محصول مجاز نیست.
  - قیمت تخفیف نباید از قیمت اصلی بیشتر باشد.
  - موجودی رزروشده نباید از موجودی کل بیشتر باشد.
- صفحه ویرایش محصول بازچینی شد تا محصول آماده/استودیویی، SKU، قیمت، تخفیف، تصویر، موجودی و SEO واضح مدیریت شوند.
- صفحه جدید `/admin/inventory` اضافه شد.
- API جدید اضافه شد:
  - `GET /api/admin/inventory`
  - `PATCH /api/admin/inventory/{variantId}/adjust`
- فیلتر فروشگاه برای محصولات تخفیف‌خورده، آماده و قابل شخصی‌سازی اضافه شد.
- دیتابیس جدید برای جلوگیری از تداخل با نسخه‌های قبلی:
  - `TatakaeEmbroideryCommerce_Phase01CatalogSkuV1`

## مرحله بعد

مرحله ۲ باید روی چرخه سفارش کار کند:

- وضعیت‌های سفارش
- تولید/گلدوزی
- بسته‌بندی
- ارسال
- مرجوعی و لغو
- اتصال کامل به موجودی
