# Phase 05 - Coupons & Discount Flow

این مرحله برای واقعی‌تر شدن فروشگاه Tatakae، جریان کد تخفیف را از حالت نمایشی به حالت قابل استفاده در Checkout تبدیل می‌کند.

## قابلیت‌ها

- اعتبارسنجی کد تخفیف قبل از ثبت سفارش
- محاسبه مبلغ تخفیف و مبلغ قابل پرداخت در Checkout
- پیام واضح برای کد نامعتبر، منقضی، غیرفعال، ظرفیت‌تکمیل یا حداقل‌مبلغ ناکافی
- پشتیبانی از تخفیف درصدی و مبلغ ثابت
- سقف‌گذاری تخفیف مبلغ ثابت تا حداکثر جمع سبد
- API عمومی برای quote کد تخفیف
- حفظ منطق نهایی تخفیف در سمت سرور هنگام ثبت سفارش

## مسیرهای API

```http
POST /api/coupons/quote
```

نمونه درخواست:

```json
{
  "code": "WELCOME10",
  "cartSubtotal": 1200000
}
```

نمونه پاسخ موفق:

```json
{
  "code": "WELCOME10",
  "isValid": true,
  "message": "کد تخفیف با موفقیت اعمال شد.",
  "cartSubtotal": 1200000,
  "discountAmount": 120000,
  "payableSubtotal": 1080000,
  "type": "Percentage",
  "value": 10,
  "minimumOrderAmount": 500000,
  "usageLimit": 100,
  "usageCount": 0,
  "endsAt": null
}
```

## صفحات تغییرکرده

- `/checkout` برای اعمال و نمایش کد تخفیف
- `/admin/coupons` از قبل وجود داشت و با این جریان هماهنگ شد

## نکته امنیتی

نمایش quote در Checkout فقط برای تجربه کاربری است. محاسبه نهایی تخفیف همچنان در `OrderService.CheckoutAsync` در سمت سرور انجام می‌شود؛ بنابراین کاربر نمی‌تواند با تغییر UI مبلغ سفارش را دستکاری کند.
