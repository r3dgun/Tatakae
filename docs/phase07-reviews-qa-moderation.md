# Phase 07 - Reviews & Q/A Moderation

در این مرحله سیستم نظر و پرسش‌وپاسخ محصول کامل‌تر شد.

## قابلیت‌ها

- نظر فقط بعد از خرید و تحویل سفارش قابل ثبت است.
- نظر مشتری ابتدا با وضعیت Pending ذخیره می‌شود.
- ادمین می‌تواند نظر را Approved، Rejected یا Hidden کند.
- پاسخ ادمین به نظر مشتری ذخیره و در صفحه محصول نمایش داده می‌شود.
- خلاصه امتیاز محصول شامل میانگین، تعداد نظر، هیستوگرام، تعداد خریدار و درصد پیشنهاد نمایش داده می‌شود.
- پرسش مشتری در دیتابیس ذخیره می‌شود و بعد از پاسخ ادمین عمومی می‌شود.
- صفحه‌های `/admin/questions` و `/admin/reviews` به API واقعی وصل شدند.

## تست‌ها

- `ProductEngagementServiceTests` برای منطق ثبت نظر بعد از تحویل، رد نظر قبل از تحویل، ثبت پرسش و پاسخ ادمین.
- `ProductEngagementRouteTests` برای route و authorization کنترلرهای ادمین.
