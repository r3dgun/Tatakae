# Mobile desktop-like drop fix

The previous mobile rescue stacked the VOID/NIGHT SIGNAL drop sections, which changed the editorial desktop composition too much.

This fix keeps the desktop relationship on phones:

- VOID: number column + title/copy column + tall image column.
- SIGNAL: image column + title/copy column + signal bars.
- The reveal circle remains visible and controlled on phones so the section keeps the Ink Editorial look instead of becoming a plain card.
- Small text is reduced or hidden on very narrow screens to preserve the original visual hierarchy.
