# Phase 01 - Friendly Variant Manager

این نسخه بخش تنوع محصول/SKU را از حالت جدول خام به ساختار کارت‌محور تبدیل می‌کند.

## تغییرات

- خلاصه سریع تعداد تنوع، موجودی کل، موجودی قابل فروش و کم‌موجودی
- ساخت سریع تنوع‌ها بر اساس ترکیب سایز × رنگ
- کارت قابل باز و بسته شدن برای هر SKU
- نمایش وضعیت هر تنوع: آماده فروش، کم‌موجودی، ناموجود، غیرفعال
- محاسبه قیمت نهایی و درصد تخفیف در خود کارت
- جداسازی فیلدها به بخش‌های: شناسه و رنگ، قیمت، موجودی، رسانه و عملیات
- طراحی موبایل‌فرندلی برای پنل ادمین

## نکته

برای محصول آماده، همین SKU مستقیم فروخته می‌شود. برای محصول قابل شخصی‌سازی، مشتری ابتدا تنوع را انتخاب می‌کند و بعد وارد استودیو می‌شود.
